Como contar a história de Vera Cruz

Texto-base para edição, checagem e ampliação com fontes locais.

Comece pelas fontes

Documentos oficiais, jornais, mapas, fotografias, objetos, prédios, paisagens e depoimentos podem ser comparados para construir uma narrativa mais confiável.

Escute versões diferentes

Uma mesma transformação pode ser lembrada de modos distintos. Registrar divergências é mais honesto do que apagar vozes para criar uma história lisa demais.

Mostre as referências

Cada página deve informar de onde vieram os dados, quem concedeu entrevistas, quem produziu as fotografias e quando a pesquisa foi atualizada.

Inclua aqui as fontes utilizadas, os créditos das imagens e a data da última revisão.

Checklist editorial

  • Conferir nomes e datas
  • Citar fontes
  • Pedir autorização de imagem
  • Revisar com moradores
  • Informar a atualização
